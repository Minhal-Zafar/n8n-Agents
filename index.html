Can I import these into my own n8n?

Yes. Download any workflow JSON, then in n8n go to Workflows → Import from file. Connect your own credentials (OpenAI, Gmail, Slack…) and replace the YOUR_… placeholders. Each workflow has a sticky note explaining its setup.

How were they checked?

Every node type, version, parameter and connection is validated against the node definitions published in n8n's own packages (n8n-nodes-base and @n8n/n8n-nodes-langchain). They still need your credentials and a test run in your instance before going live.

Which ones run in production?

The two email-triage workflows run for a B2B supplier, handling classification, drafting, manager approval and HubSpot sync. Client details have been anonymised. The other nine are original, deploy-ready builds that show how I'd solve each problem.

Why a human approval step?

Anything that sends money, publishes content or replies to a customer pauses for a one-click approval (n8n's send-and-wait). The AI does the work, and a person stays accountable for the outcome.
